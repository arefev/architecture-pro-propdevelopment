# Проверочный лист безопасности системы PropDevelopment

## Ключевые разделы системы

1. Управление доступом - есть несколько точек регистрации нового клиента, координации между этими точками нет. Со стороны систем обработки данных нет ограничений на доступ к данным.
2. Безопасность данных - нарушен контроль данных, пользователи видят чужие ФИО.
3. Защита инфраструктуры - системы используют API управляющих компаний без единых политик по безопасности и без системного контроля за передаваемыми данными.
4. Управление инцидентами - Специалист по ИБ один на всю компанию, нет оповещений об инцидентах и подозрительной активности.
