| Роль                    | Права роли                                                                                                                                                                       | Группы пользователей                                                                             |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| **cluster-admin**       | Полный административный доступ ко всем ресурсам кластера. Создание/удаление неймспейсов, управление CRD, сетевыми политиками, StorageClass, RBAC-правами.                        | DevOps-инженеры; инженер по эксплуатации Kubernetes; руководители ИТ-инфраструктуры.             |
| **namespace-admin**     | Полный доступ в рамках конкретного namespace: создание и управление Deployment, Service, Ingress, Secret, ConfigMap, PVC; просмотр логов; перезапуск Pod; масштабирование.       | Старшие разработчики продуктовых команд; инженеры эксплуатации отдельных доменов.                |
| **developer-edit**      | Создание и изменение ресурсов в namespace своего продукта: Deployment, Service, ConfigMap, Secret (только создание/чтение своих); запуск Job; работа с Pod exec.                 | Разработчики функциональных команд PropDevelopment.                                              |
| **developer-view**      | Только просмотр ресурсов: Pod, Service, Deployment, Ingress, ConfigMap, Secret (только список, без чтения содержимого); просмотр логов Pod; запрет на изменения.                 | QA-инженеры; бизнес-аналитики; стажёры команд разработки.                                        |
| **security-privileged** | Просмотр секретов (Secret), просмотр и редактирование RBAC-объектов, аудит ресурсов, просмотр конфигурации сети и политики безопасности; запрет на изменения рабочих нагрузок.   | Специалист по информационной безопасности.                                                       |
| **ops-config**          | Управление конфигурацией кластера: ограниченный доступ к ClusterRole, ClusterRoleBinding; работа с NetworkPolicy; настройка мониторинга; управление storage в пределах политики. | Инженеры по эксплуатации (операционные команды).                                                 |
| **ci-cd-automation**    | Создание/обновление Deployment, Job, CronJob, ConfigMap, Secret в пределах namespace, перезапуск Pod; отсутствие интерактивных действий.                                         | CI/CD-системы (например, GitLab CI, GitHub Actions).                                             |
| **readonly-audit**      | Глобальный read-only доступ ко всему кластеру: просмотр всех ресурсов, логов, конфигураций; без возможности читать содержимое Secret.                                            | Служба аудита, внутренний контроль, команда Data (для исследования инфраструктурных метаданных). |
